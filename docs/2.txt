================================================================================
1. RINGKASAN PERUBAHAN
================================================================================
Pembaruan besar ini mencakup tiga pilar utama pada aplikasi SIKERA:
1. Restrukturisasi Alur Evaluasi Riset & Pemisahan Menu Bank Soal Admin:
   - Pre-Test dikerjakan per modul tepat sebelum mahasiswa dapat membuka subbab
     atau pembaca Flipbook PDF pada modul tersebut.
   - Post-Test diubah dari per modul menjadi 1x Post-Test akhir terpadu yang
     terbuka otomatis 3 hari (72 jam) sejak seluruh subbab pada semua modul
     diselesaikan (`users.all_modules_completed_at + 3 hari`).
   - Indeks N-Gain dihitung menggunakan rata-rata skor Pre-Test seluruh modul
     dibandingkan terhadap skor Post-Test akhir terpadu, dan sesi mahasiswa
     tetap aktif setelah mengirim Post-Test (tidak dipaksa keluar).
   - Pada peran Super Admin, ditambahkan dua menu terpisah di bilah samping:
     * Kelola Pre-Test (`/admin/pretest-questions`): soal dikelompokkan dan
       difilter berdasarkan modul (`module_target` wajib, `question_type = 'pre_test'`).
     * Kelola Post-Test (`/admin/posttest-questions`): bank soal umum terpisah
       tanpa keterikatan modul (`question_type = 'post_test'`, `module_target = null`).
2. Migrasi Penuh Frontend ke Inertia.js v3 + React 19 + TypeScript + Tailwind v4:
   - Seluruh halaman Blade lama dihapus dan dimigrasikan menjadi 27 halaman SPA
     Inertia React TypeScript dengan mengadaptasi kerangka TailAdmin React
     (`AppLayout`, bilah samping responsif desktop/seluler, pengalih tema terang
     dan gelap, komponen UI `@base-ui/react`, dan grafik ApexCharts) serta arah
     visual editorial pada `DESIGN.md` untuk halaman publik dan autentikasi.
   - Pembaca Flipbook PDF (`pdfjs-dist` + `page-flip`) ditulis ulang sebagai
     komponen React terisolasi (`PdfFlipbookViewer.tsx`) yang dimuat secara lazy
     dengan dukungan revalidasi cache versi berkas (`?v=...`).
3. Paritas Penuh REST API (`/api/v1`):
   - Endpoint Pre-Test per modul memfilter bank soal `pre_test`, pencatatan
     progres subbab memperbarui `all_modules_completed_at`, endpoint baru
     `/api/v1/posttest` (`/status`, `GET`, `POST`) menerapkan kunci masa tunggu
     3 hari dan perhitungan N-Gain, endpoint lama `/api/v1/modules/{id}/posttest`
     mengembalikan `410 Gone`, serta penambahan CRUD API Admin untuk bank soal
     Pre-Test dan Post-Test beserta pembaruan `API_DOCUMENTATION.md`.

      `post_score`, `n_gain`, dan `kategori` tanpa mencabut token Sanctum).
    - `GET|POST /api/v1/modules/{id}/posttest` -> `410 Gone` (`ENDPOINT_DEPRECATED`).
  * `app/Http/Controllers/Api/AdminTestQuestionApiController.php`:
    - CRUD penuh `/api/v1/admin/pretest-questions` (dengan filter `?module=`)
      dan `/api/v1/admin/posttest-questions` (khusus peran `admin`).
