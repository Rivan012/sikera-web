================================================================================
1. RINGKASAN PERUBAHAN
================================================================================
Format materi subbab (module_topics) pada SIKERA diubah dari input teks HTML
menjadi unggah berkas PDF wajib, sementara modul (educational_modules) tetap
berfungsi sebagai wadah kurikulum (judul, subjudul, deskripsi, estimasi waktu,
dan banner). Berkas PDF subbab yang diunggah disimpan pada penyimpanan privat
server dan ditampilkan kepada mahasiswa dalam bentuk pembaca Flipbook PDF
interaktif (mode 1 halaman dan 2 halaman buku terbuka) yang dibangun secara
lokal menggunakan pdfjs-dist dan page-flip melalui Vite.

Video YouTube opsional pada subbab tetap dipertahankan sebagai materi
pendamping, dan data subbab lama yang belum memiliki PDF tetap menampilkan
fallback konten HTML secara aman.

4. ANTARMUKA ADMIN, MAHASISWA, & FLIPBOOK PDF
================================================================================
- Dependensi Frontend (package.json):
  * pdfjs-dist (^6.5.438)
  * page-flip  (^2.0.7)

- Bundel Vite & Styling:
  * vite.config.js: entry point terpisah resources/js/flipbook.js (hanya dimuat
    di halaman baca subbab yang memiliki berkas PDF).
  * resources/js/flipbook.js: mesin pembaca PDF Flipbook dengan fitur:
    - Render halaman PDF resolusi tinggi via Web Worker lokal pdfjs-dist.
    - Pembalikan halaman realistis via StPageFlip (mode 2 halaman buku terbuka
      di desktop dan 1 halaman di mobile, dengan tombol tukar mode).
    - Kontrol zoom 75% hingga 200% + reset 100%.
    - Panel thumbnail "Daftar Halaman" dengan penanda aktif spread.
    - Input lompat halaman, slider progres, mode layar penuh, tombol "Buka PDF",
      serta pintasan keyboard (ArrowLeft, ArrowRight, PageUp, PageDown, Home, End).
    - State loading, error (dengan tombol muat ulang & buka langsung), dan
      dukungan penuh prefers-reduced-motion.
  * resources/css/app.css: gaya lembar buku flipbook, lipatan tengah halaman,
    dan mode layar penuh pada tema terang maupun gelap.

- Blade Views:
  * resources/views/admin/modules/index.blade.php: form unggah PDF untuk modul
    baru & tambah subbab, daftar status PDF Flipbook vs HTML Lama, serta modal
    Ubah / Ganti PDF dan modal konfirmasi hapus subbab/modul.
  * resources/views/modules/topic.blade.php: halaman pembaca Flipbook PDF,
    pindah cepat antar subbab, fallback HTML lama, dan video YouTube opsional.
  * resources/views/modules/show.blade.php: daftar subbab dengan penanda
    Flipbook PDF & ukuran berkas, tata letak judul bersih di bawah banner SVG.
  * resources/views/modules/index.blade.php: katalog modul dengan ringkasan
    jumlah Flipbook PDF dan progres belajar.
